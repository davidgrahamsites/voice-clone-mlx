Two apps.
One honest handoff.

The producer and the reader are separate by design. Voice Studio can be removed without making Voice Reader choose a model by accident; Voice Reader consumes only an immutable, checked voice bundle.

01 / Voice Studio

Make the evidence.

Record a script or a day of natural speech. Transcribe locally, detect overlap, reject contaminated clips, align known text, and preserve style and provenance.

02 / Voice Reader

Give it something to say.

Import writing you own or are authorized to use. Review the extracted text, select a verified voice bundle, generate resumable chunks, and export audio.

Built like a
recording session.

Small, inspectable stages make it possible to pause, review, resume, or replace one part without losing the source recording or the meaning of the handoff.

01

Capture

A two-session, 30-minute script gives the first pilot clean text, style markers, calibration, and phonetic coverage.

02

Curate

Local Whisper timestamps speech. Speaker and overlap gates reject a whole clip when another voice appears.

03

Train

A pinned provider recipe creates a source checkpoint. Evaluation happens on held-out prompts before promotion.

04

Read

Voice Reader loads the selected bundle independently and writes safe, resumable WAV output.

The handoff

Nothing gets lost between the apps.

JSONL (one JSON object per line) manifests keep each utterance tied to exact text, style, timing, source session, and checksums. The model bundle records its base revision, runtime format, license, and acceptance evidence.

That paperwork is not decoration. It is how the Reader knows which voice it is loading—and how you can reproduce or roll back a result later.
