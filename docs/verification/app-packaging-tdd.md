## What the end-to-end run exposed

Building into a directory far from the repo produced a correct but ugly hop —
ten `../` segments followed by an absolute-looking tail. It resolves fine, but
it made the real limit of "deterministic" explicit, so three tests were added
rather than leaving it to be discovered later:

- `test_plist_is_identical_wherever_it_is_built` — the plist has no paths, so
  build location cannot change it. This is the strong determinism claim.
- `test_launcher_hop_reflects_the_output_location` — the launcher **does**
  differ with depth, and that is the deliberate cost of baking in no absolute
  path. Asserted so the trade-off is documented in executable form.
- `test_bundle_inside_the_repo_gets_a_short_hop` — the intended layout stays
  tidy at `../../../..`.

The user-facing consequence is recorded in the module CONTEXT: moving a bundle
on its own breaks it; move it with the repo, or rebuild.

## Security pass — shell injection and replacement identity

The first implementation shipped two real holes, both found in review.

### Red

```bash
$ python3 -m pytest tests/packaging/test_app_bundle.py -q
15 failed, 47 passed in 1.04s
```

Not a cosmetic red: two of the new tests **actually executed `touch pwned`**
through the generated launcher. That was live command execution, not a
theoretical finding.

| Failing group | Why it failed |
|---|---|
| `TestLauncherQuoting` (16 cases: 4 test functions, three of them parametrized over five hostile repo names) | `relative_repo` was interpolated into a double-quoted shell string, so a repo directory named ``evil`touch pwned` `` or `evil$(touch pwned)` executed its payload **every time the app launched**. The `/bin/sh` execution tests created the marker file. |
| `TestReplacementIdentity` (5) | `MARKER`, `MARKER_KEY`, and the identity check did not exist. `_remove_bundle` accepted any directory carrying an `Info.plist` — which every macOS app has — so `--replace` would delete a third-party `Voice Studio.app`, or a renamed Reader bundle, and its contents with it. |

### Green

### Fix 1 — `shlex.quote` on the relative hop

The hop is now emitted as a separate, quoted token:

```sh
repo=$(cd "$here"/'../../../../evil$(touch /tmp/PWNED_VCG)' && pwd)
```

Verified outside the suite with a directory literally named
`evil$(touch /tmp/PWNED_VCG)`: the prelude runs, exits `0`, and
`/tmp/PWNED_VCG` does not exist. Inside the suite, five hostile names —
`"`-breaking, backtick, `$( )`, single-quote, and `$HOME` — are parametrized
across an exact-line template match, a real `/bin/sh` execution asserting no
side-effect file appears, and a positive test that ordinary paths still
resolve.

### Fix 2 — tool marker plus expected identity

Every bundle now carries `VCMLXBuiltBy = voiceclonemlx.packaging.app_bundle` in
its plist, and `_check_replaceable` requires **both** that marker and
`CFBundleIdentifier == spec.bundle_id` before anything is deleted. The second
check is not redundant: without it, rebuilding Studio would delete a Reader
bundle that had been renamed `Voice Studio.app`. Unreadable and non-dict plists
are refused.

Verified outside the suite: a third-party `Voice Studio.app` with a valid plist
and a `user-data.txt` is refused with *"not built by this tool"*, and the file
survives.

The marker is a constant, so determinism is unaffected — the plist is still
byte-identical across builds and locations.

### Three test bugs in my own suite, fixed

Worth recording because two of them made tests pass for the wrong reason:

1. `sh -c prelude` sets `$0` to `/bin/sh`, so `dirname "$0"` resolved to
   `/bin` — the execution tests were not exercising the launcher at all. The
   launcher path is now passed as `$0`.
2. A `script.count("$(") == 3` assertion was wrong for a hostile name that
   itself contains `$( )`. Replaced with exact equality against the quoted
   template — stronger and unambiguous.
3. Two assertions encoded superseded behaviour: `match="not a bundle"` (the
   refusal message deliberately changed to "not built by this tool") and
   `'"$here/../../../.."'` (quoting moved the quote boundary). Both updated;
   intent preserved.

## Deliberately not built

Icons, a bundled Python runtime, codesigning, notarization, DMG packaging.
The bundle wraps the system `python3` and is unsigned, so Gatekeeper warns on
first launch. That is the correct shape for a personal local utility and the
wrong shape for distribution — the distinction is stated in the CONTEXT rather
than papered over.
